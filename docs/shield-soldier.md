# Shield Soldier

The Shield Soldier is a tactical ground enemy introduced in M8.4.

## JSON

```json
{
  "kind": "shield",
  "x": 2320,
  "y": 498,
  "left": 2150,
  "right": 2600,
  "vision": 420,
  "speed": 95,
  "health": 6,
  "shieldAngle": 130,
  "fireCooldown": 2.4
}
```

Frontal and roughly level bullets are blocked while the shield is raised. Shots from behind or substantially above bypass it. Explosions always bypass the shield and stagger the soldier. Jump pads launch it, water slows it, ice reduces stagger braking, conveyors carry it, and its weight triggers falling platforms.
