# M7 Regression Checklist

- Start a new game and complete levels 1 through 10 in sequence.
- Confirm that each completion unlocks the next level.
- Restart the application and confirm that the highest unlocked level remains available.
- Confirm that level 10 shows **Play campaign again** and returns to level 1.
- Verify that all ten JSON files load from `assets/levels` when running from the repository root.
- Temporarily move the external JSON files and verify that embedded resources still load.
- Test checkpoints and goals in every level.
- Verify boxes, jump pads, pressure plates, conveyors, one-way platforms, falling platforms, ice and water in their introduction levels.
- Verify the mixed-mechanics levels 9 and 10.
- Confirm the level editor can open all ten JSON files.
