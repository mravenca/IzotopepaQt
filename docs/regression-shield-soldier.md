# Shield Soldier regression checklist

- [ ] Soldier patrols within left/right limits.
- [ ] It advances, defends, fires, and returns to movement.
- [ ] Frontal bullets produce blue shield sparks and no damage.
- [ ] Bullets from behind damage it.
- [ ] Bullets from above damage it.
- [ ] Explosions bypass the shield and stagger it.
- [ ] Jump pads launch it and lower the shield temporarily.
- [ ] Water slows movement and firing.
- [ ] Conveyors and ice affect movement.
- [ ] Falling platforms trigger and wait for it before respawning.
- [ ] Score is awarded once.
- [ ] F3 displays shield state and cooldown.
- [ ] Drone, Turret, Charger, and legacy enemies still work.
