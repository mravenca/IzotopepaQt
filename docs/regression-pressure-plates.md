# Pressure plate regression checklist

- [ ] Standing on a plate opens the matching door.
- [ ] Leaving the plate closes a door that was not otherwise unlocked.
- [ ] A pushable box keeps the plate active after the player leaves.
- [ ] Crates and barrels also contribute one weight unit.
- [ ] A door opened with its key stays open after the plate is released.
- [ ] A wall switch still opens its matching door permanently.
- [ ] A plate does not repeatedly beep while its state is unchanged.
- [ ] Door collision updates when the plate is pressed and released.
- [ ] Jump pads, moving platforms, crates, barrels, boxes, and ladders still work.
- [ ] All three JSON levels load successfully.
