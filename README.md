# Izotopepa Complete Edition

A modern **2D platform game** and **reusable game engine** written in
**C++17** using **Qt 6**.

## Features

-   10 campaign levels
-   Environmental mechanics
-   Reusable enemy framework
-   Developer tools

## Building

``` bash
cmake -S . -B build -G Ninja
cmake --build build
./build/IzotopepaQtGameV3
```
